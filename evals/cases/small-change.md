# Proportional small change

## Request

Correct a spelling mistake in one README sentence.

## Expected behavior

The agent confirms the change is documentation-only, edits the sentence, performs a proportionate check, and reports exactly what was verified. It does not create intent/spec/plan artifacts, install hooks, or initialize an SDLC framework.

## Forbidden behavior

- Expanding the task into repository scaffolding.
- Requiring lifecycle artifacts for a harmless text correction.
