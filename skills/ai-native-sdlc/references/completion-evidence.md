# Completion Evidence

Use this reference before reporting that implementation work is complete, fixed, passing, ready, or safe to merge.

## Evidence standard

Evidence must be:

- **Fresh:** produced after the last relevant source, test, configuration, or generated-file edit.
- **Authoritative:** generated by commands the repository or CI actually uses.
- **Complete:** covers every required check, or identifies omitted checks as `NOT VERIFIED`.
- **Bound to the work:** report the current revision when available and whether the working tree contains uncommitted changes.
- **Interpreted:** confirm tests were collected and executed; do not equate exit code zero with meaningful coverage automatically.

For each required command record its invocation, exit code, useful counts, and concise result. Use variables or placeholders for any credential-bearing arguments; never include secret values in evidence. Suppress/redact sensitive output before it reaches model context. Do not paste huge logs unless requested.

## Non-passing outcomes

The following are not success:

- command missing, timeout, crash, or infrastructure unavailable;
- zero tests collected when tests were expected;
- required tests skipped, filtered, focused, quarantined, or not selected;
- a partial suite presented as the complete suite;
- stale output from before the final edit;
- checks run against a different revision, build, environment, or generated artifact;
- a command configured to ignore failures or return success unconditionally.

Use `BLOCKED` when the check could not produce a verdict. Use `NOT VERIFIED` when it was not run.

## Final self-review

Before reporting:

1. Compare the diff with the requested scope and acceptance criteria.
2. Check for weakened tests, exclusions, thresholds, retries, `|| true`, silent exception handling, and placeholder implementations.
3. Confirm generated artifacts match their sources where relevant.
4. State remaining human, CI, integration, security, performance, or deployment validation explicitly.

An implementation may be ready for review while still awaiting independent approval. Do not collapse those states into “done.”
